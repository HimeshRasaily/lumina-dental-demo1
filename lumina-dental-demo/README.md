# Lumina Dental Studio — Demo Website

A premium, responsive fictional dental practice website built with Next.js, TypeScript, Tailwind CSS, Framer Motion and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

1. Push this repository to GitHub.
2. Import the repository into Vercel or Netlify.
3. Use the default Next.js build settings.
4. Deploy.

## Before using for a real clinic

This is a fictional concept website for sales demonstrations. Replace the clinic name, address, phone, email, dentist biography, services, images and all sample review content with client-approved information.

The appointment form currently demonstrates client-side validation and a success state only. It does **not** transmit or store enquiries. Connect a secure form provider or API endpoint before production. Do not collect patient health information through this demo. Any real patient-data workflow requires appropriate HIPAA safeguards and agreements.

The contact details, dentist identity, testimonials and address are illustrative and must not be represented as a real practice.
